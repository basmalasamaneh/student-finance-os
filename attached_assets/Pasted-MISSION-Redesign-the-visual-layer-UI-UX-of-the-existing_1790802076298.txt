MISSION

Redesign the visual layer (UI/UX) of the existing Student Financial OS app into a premium, modern, professional fintech product with a rich gold theme, and make the mobile experience feel like a native iOS/Android app.

This is a presentation-layer refactor only. Everything built in Prompts 1–7 must keep working exactly as it does today.

ABSOLUTE SAFETY RULES (READ FIRST)
Do NOT change: database schema, migrations, API routes, server logic, auth/session logic, route paths, financial calculation functions, money representation, i18n keys that already exist, seed/demo data, or any business logic.
Do NOT delete or rename any existing page, route, component export, hook, or feature. If a component needs a new look, restyle it in place (same file, same props, same exports). Add new props only as optional with safe defaults.
Do NOT restart the project and do NOT scaffold a second app or a parallel design system. Extend and migrate the existing one.
Do NOT hardcode values that are dynamic. All numbers, names, and states keep coming from existing data sources.
Existing translations (English + Arabic) must keep working. New strings must be added to both languages through the existing i18n system.
Existing features to protect and re-verify at the end: authentication, onboarding, profile, student Home dashboard, Money/accounts/wallet, campus payments + receipts, Transactions + filters, Budget/Plan (income, university plan, housing, transportation, recurring), Savings Goals (create/edit/contribute/pause/resume/complete/archive/history).
The financial system remains simulated only. Nothing in this prompt adds real payments.
Work in the phases below, in order. After each phase, run the app and confirm nothing is broken before continuing.

PHASE 1 — GOLD DESIGN TOKENS (SINGLE SOURCE OF TRUTH)

This section REPLACES the old "DESIGN SYSTEM → Colors" section of the master spec. Indigo/Mint are no longer brand colors.

Create or update semantic design tokens (CSS variables / Tailwind theme extension) and make all components consume tokens only — no raw hex in components.

Gold usage discipline (TRUST-FIRST — very important)

The app must feel like a serious, trustworthy bank-grade product with a gold identity, NOT a flashy crypto/casino look.

60 / 30 / 10 rule: ~60% calm neutral surfaces (ivory/white in light, near-black in dark), ~30% ink/charcoal for text, navigation, and structure, ~10% gold used as the accent.
Gold is for: the ONE hero element per screen (balance card or main CTA), active navigation state, progress fills, key icons, and focus rings. Gold is NOT for large page backgrounds, body text, every card border, or decorative patterns.
Max one strong gold gradient per screen. Everything else is flat.
No glitter, heavy glow, bevels, or ornamental textures. Premium = restraint, space, and precise typography.
Numbers and clarity always win over decoration.

Contrast & accessibility (non-negotiable)
Gold text on white/ivory must use gold-700 or darker. Never gold-400/500 as text on light.
Text on gold fills must use on-brand (dark bronze), never white.
Body text ≥ 4.5:1, large text/icons ≥ 3:1, in BOTH light and dark themes.
Visible gold focus ring (2px, offset) on all interactive elements.
Typography
Keep the current font stack if it already supports Arabic well; otherwise use Inter (Latin) + IBM Plex Sans Arabic or Noto Sans Arabic (Arabic), loaded through the existing font mechanism.
Tabular/lining numerals for all money values (font-variant-numeric: tabular-nums) so columns align.
Type scale: Display (balance) 36–44 / H1 28 / H2 22 / H3 18 / Body 16 / Caption 13. Weight contrast: balances semi-bold/bold, labels medium.
Money component: currency symbol smaller and lighter than the amount; decimals slightly smaller/lighter; negative and positive amounts clearly distinguishable (sign + icon, not just color).
Shape, elevation, spacing
Radius: cards 20px, inputs/buttons 14px, chips full-round, bottom sheets 28px top corners.
Elevation: light mode = soft warm shadows (rgba(120,90,20,0.08–0.14)); dark mode = 1px subtle gold-tinted borders + faint inner glow instead of heavy shadows.
4/8 spacing system; generous whitespace; consistent 16px screen gutters on mobile.
