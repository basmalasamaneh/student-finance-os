PHASE 2 — RESTYLE THE SHARED COMPONENT LIBRARY (IN PLACE)

Restyle the existing reusable components from Prompt 1. Keep file names, exports, and props.

Buttons: Primary = gold gradient fill + on-brand text, 52px height on mobile, subtle press scale (0.97) + pressed color; Secondary = outlined gold; Tertiary = text; Destructive = error color. Loading state with spinner that keeps button width. Disabled state clearly different.
Inputs / selects / search: 52px height, floating or clear top labels, gold focus ring, clear button, inline validation messages. Amount inputs: large centered numeric style with inputmode="decimal".
Cards: flat surface, 20px radius, optional "premium" variant with gold-shine overlay (used for hero balance, goal highlight, campus receipt).
Balance hero card: gold gradient, large tabular balance, eye icon to hide/show balance (persist the preference), sub-line with account count, optional tiny sparkline; "Quick actions" row beneath it (Add money, Send, Request, Pay campus — only those that already exist or are marked Coming soon).
Transaction rows: circular category icon in gold-tinted container, title + subtitle, right-aligned tabular amount, date group headers ("Today", "Yesterday"), sticky group headers while scrolling.
Progress bars / goal rings: gold gradient fill on a gold-200 (light) / 
#33291A (dark) track; animated on mount (respect reduced motion); circular ring variant for goals.
Badges/chips: soft tinted backgrounds, never saturated blocks.
Tabs / segmented controls: pill-style segmented control with animated gold indicator.
Charts: restyle to the gold palette, rounded bars, soft gridlines, tooltips with token colors, accessible text alternatives.
Empty / loading / error / success states: elegant gold line-art style illustration or icon, short helpful copy, one clear primary action. Loading = skeleton shimmer matching the real layout (not spinners for page loads).
Toasts: top on mobile under the safe area, bottom-right on desktop; success/error with icon.
Dialogs: on mobile, all dialogs/forms that used centered modals become bottom sheets (see Phase 4). On desktop they stay centered dialogs.
Icons: one consistent icon set, 1.75px stroke, rounded caps; RTL-mirrored where directional (arrows, chevrons, back).
